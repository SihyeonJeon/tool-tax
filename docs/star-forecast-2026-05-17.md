## Reading

High-star repos in this category usually have at least one of:

- a broad runtime surface: plugin/proxy/MCP/server/wrapper;
- a dramatic visible number near the top of the README;
- a demo video or screenshot;
- package-manager install;
- a founder or community distribution channel;
- support for a named agent host such as Claude Code, Cursor, Codex, Gemini, or Pi.

`tool-tax` currently has:

- clear category fit: MCP/tool schema bloat;
- small CLI with one runtime dependency;
- CI budget gate;
- generated progressive-loading pack;
- concise README;
- PyPI package available;
- terminal demo GIF in the README;
- GitHub Action integration;
- package-manager distribution through PyPI;
- live MCP stdio probing with public MCP scan reports.
- experimental runtime MCP stdio proxy with lazy schema loading.
