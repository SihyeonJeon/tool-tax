# Publication Note

Safe claim:

> `tool-tax` measures the up-front schema token cost of MCP and agent tool
> catalogs and can generate a smaller progressive-loading index.

Current example:

- 5 demo tools
- 1,144 estimated full-schema tokens
- 309 estimated slim-index tokens
- 73.0% smaller index in the included fixture

Claims not made:

- Provider bill reduction.
- Runtime accuracy improvement.
- Complete MCP compatibility.
- Security validation of tool schemas.
