# Roadmap

## Next

- YAML support for common MCP config files.
- `tool-tax diff base.json head.json` for PR comments.
- GitHub Action that uploads Markdown reports as artifacts.
- More real-world fixture packs from public MCP servers.

## Later

- Optional exact tokenizers for major providers.
- OpenAPI slicing by tag, path, or operation group.
- MCP proxy adapter that serves `tool-index.json` first and schema on demand.

## Not Now

- Runtime tool-call compression.
- Provider bill claims.
- Security validation of tool schemas.
